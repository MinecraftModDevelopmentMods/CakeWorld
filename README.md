# Cake World

Cake World is a family friendly Minecraft mod that turns the world into a giant confectionery adventure.

Explore chocolate meadows, gingerbread villages, gummy jungles, hot fudge caverns and floating meringue islands. Discover unusual foods and creatures, then record what you find in the Explorer’s Cookbook.

Cake World also serves as an example and test mod for [MMD OreSpawn](https://www.curseforge.com/minecraft/mc-mods/mmd-orespawn).

## Current Features

- Edible biomes across the Overworld, Nether and End
- Chocolate, biscuit, marshmallow, caramel, icing and other unusual terrain
- Lemonade, hot fudge and other themed fluids
- Cake World creatures, foods, tools and structures
- The Explorer’s Cookbook discovery system
- Gentler Cake World mobs on Easy and Normal, with real danger on Hard
- Optional Base Metals integration

Cake World is still in alpha. Some artwork, sounds, structures and gameplay features are unfinished or use temporary assets.

## Requirements

- Minecraft 1.18.2
- Forge 40.3.0 or another compatible Forge 40 release
- Java 17
- MMD OreSpawn 4.0.16.118021 or newer compatible 4.x release

## Installation

1. Install Forge for Minecraft 1.18.2.
2. Download Cake World and MMD OreSpawn.
3. Put both JAR files in your Minecraft `mods` folder.
4. Start Minecraft and create a new world.

Cake World generation is selected when a fresh world is created. Existing worlds are not automatically converted.

As this is an alpha release, back up any world you care about before using it.
