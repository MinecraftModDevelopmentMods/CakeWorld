# CakeWorld 1.18.2 build fixture

The `tools` directory contains the checksum-sealed Forge 1.18.2 Mavenizer
compatibility tool used by the ForgeGradle 7 build. It is a build-only input
copied from the OreSpawn 1.18 build and must never be added to a dependency
configuration or published CakeWorld artifact.

See `tools/README.md` for provenance, licensing, the documented patch, and the
expected SHA-256 checksum.
